# Verification Checklist — `wsi-metastasis-seg`

A module is **not complete** until its gate passes. Each gate is a concrete
shell command with a quantitative pass criterion. "It ran without crashing" is
not a criterion; every gate below has a number attached to it.

**Rules**
1. Gates run in order. `V(n)` may assume `V(n-1)` passed.
2. A gate that passes by accident (e.g. a metric within range because the
   pipeline produced nothing) is a failed gate. Where relevant, gates assert
   both an upper and a lower bound.
3. `make verify` runs V0–V6 (fast, < 12 min). `make verify-full` adds V7–V10.
4. Record the run in `artifacts/reports/verify_{date}.log`. CI runs V0–V6 on
   every PR against `tests/fixtures/mini/` (3 synthetic slides, 40 MB).

**Fixtures.** `tests/fixtures/mini/` contains three deterministic synthetic
pyramidal TIFFs generated by `scripts/make_fixtures.py`:
`synth_tumor.tif` (known 2.00 mm² lesion), `synth_normal.tif`,
`synth_edge.tif` (dimensions deliberately not a multiple of 256, alpha=0
border, non-power-of-two `level_downsamples`).

was documented but never implemented, and a wandering loss on 200 *different*
batches looked like an ambiguous result rather than an absent test.
